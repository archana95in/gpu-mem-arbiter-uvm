# Phase planning docs

The actual task briefs used to direct each phase of this project's AI-assisted development (see [`AI_METHODOLOGY.md`](../../AI_METHODOLOGY.md)). Kept as primary-source evidence of process, not rewritten to read as narrative prose.

- `PROJECT_PLAN.md` — original phase breakdown for the whole project.
- `PHASE3_PLAN.md`, `PHASE4_PLAN.md`, `PHASE5_PLAN.md` — the brief for each phase.
- `PHASE5_LOG.md` — raw working notes from the Phase 5 investigation, written as it happened.

These read as task instructions because that's what they are — written to direct an AI coding session with no memory of prior work. Kept as-written rather than edited to sound less like what they actually were.
